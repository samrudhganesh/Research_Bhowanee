# Known limitations

- Karnataka-specific total-cost observations exist for only two crops, with one additional partial family-labour observation. National benchmarks are not Karnataka budgets.
- Rainfed/irrigated cost and yield splits, measured crop-hazard yield losses, most crop-specific costs and component costs, and zone-level yield/cost observations were not retrieved. No artificial estimates were added.
- Only five zones contain retrieved numeric rainfall profiles; no invented geographic boundaries or map was added.
- Source URL liveness, source factual correctness, all Excel formulas in a calculation engine, and agricultural recommendation validity have not been independently verified.
- All original chart metadata retained. Analytical charts were extended, not reproduced pixel-for-pixel. Some existing fixed comparison copy and record selections remain workbook-edition-specific. Some tooltips cannot provide record metadata for grouped multi-source series; read the chart scope and related table.
- Full runtime, layout screenshot review, accessibility certification, dependency audit, complete type checking and production build could not be performed due to missing npm dependencies and blocked registry access. A genuine npm lockfile was not generated. Generate one with `npm install` and commit it before switching to `npm ci`.
- No claim of complete prompt fulfillment, perfect visual rendering, or fully certified deployment is made. This is an integrated enhancement with verified dataset fidelity and static checks.
